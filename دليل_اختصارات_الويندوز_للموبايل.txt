========================================================================
     💻📱 دليل اختصارات الويندوز الكاملة للتحكم في الموبايل
========================================================================

🎯 التبديل الأساسي:
- [Alt + Space] : التبديل الفوري بين شاشة اللاب توب والموبايل (ضغطة تروح، ضغطة ترجع).
- [Esc]         : يرجعك لشاشة اللاب توب في أي وقت.

------------------------------------------------------------------------
🌐 1. تبديل لغة الكتابة (زي الويندوز بالضبط):
------------------------------------------------------------------------
- [Alt + Shift]  أو  [Ctrl + Shift]  أو  [Win + Space] :
  تبديل فوري للغة الكتابة بين (العربي ↔ الإنجليزي) على الموبايل!

------------------------------------------------------------------------
📋 2. اختصارات النصوص والتحرير المعتادة:
------------------------------------------------------------------------
- [Ctrl + C] : نسخ (Copy).
- [Ctrl + V] : لصق من الحافظة (Paste).
- [Ctrl + X] : قص (Cut).
- [Ctrl + A] : تحديد الكل (Select All).
- [Ctrl + Z] : تراجع (Undo).
- [Shift + الأسهم] : تظليل النصوص حرفاً بحرف.

------------------------------------------------------------------------
🪟 3. اختصارات التنقل والنظام (Windows Experience):
------------------------------------------------------------------------
- [Alt + Tab]               : فتح التطبيقات في الخلفية (Recent Apps).
- [Win + D]  أو  [Home]     : العودة للشاشة الرئيسية (Desktop / Home).
- [Win + L]                 : قفل شاشة الهاتف (Lock Screen).
- [Win + E]                 : فتح مدير الملفات (Files).
- [Win + B]                 : فتح متصفح الإنترنت (Browser).
- [Win + N]                 : سحب شريط الإشعارات (Notification Center).
- [PrintScreen] أو [Win+Shift+S] : لقطة شاشة للموبايل (Screenshot).
- [Alt + F4]                : إغلاق التطبيق الحالي / رجوع.

------------------------------------------------------------------------
🔊 4. الصوت والإضاءة:
------------------------------------------------------------------------
- [Alt + سهم فوق]  أو  [Volume Up]   : تعلية الصوت.
- [Alt + سهم تحت]  أو  [Volume Down] : توطية الصوت.
- [Alt + سهم يمين] : تزويد إضاءة الشاشة.
- [Alt + سهم شمال] : تقليل إضاءة الشاشة.

------------------------------------------------------------------------
📜 5. السكرول الطبيعي الناعم (Smooth Scroll):
------------------------------------------------------------------------
- [سهم تحت] : سكرول سلس وهادئ لأسفل في أي تطبيق أو شات.
- [سهم فوق] : سكرول سلس وهادئ لأعلى.

------------------------------------------------------------------------
🖱️ 6. الماوس:
------------------------------------------------------------------------
- [كليك شمال] : لمس وفتح وسحب (Touch / Click).
- [كليك يمين] : زر الرجوع (Back).
- [بكرة الماوس]: سكرول سريع، والضغط عليها = Home.
